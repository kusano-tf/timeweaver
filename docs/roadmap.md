# Timeweaver ロードマップ

このドキュメントは、Timeweaver の今後の開発候補を整理するためのメモである。

確定済みの仕様は `docs/specification.md` と `docs/json-format.md` を正とする。ロードマップの項目は、実装時に仕様へ昇格させてから反映する。

## 積極的に実装したい

仕様の不確実性が低く、近いタイミングで実装したい項目を置く。

- タイムライン UI 操作時のインタラクティブ性向上。
- 依存関係を持つアイテム移動時のライブプレビュー。ドラッグ対象だけでなく、確定時に依存伝播で動く後続アイテムも事前に確認できるようにする。
- タイムラインテーマの拡張。線幅、レーン高、アイテム形状、依存線スタイルなどをテーマ JSON の `tokens` に追加する。
- 表示粒度に応じた日時入力フォームの最適化。内部データは秒精度の `YYYY-MM-DDTHH:mm:ss` を維持しつつ、年表示では年中心、月表示では年月中心など、入力 UI を現在の表示粒度に合わせて簡略化する。
- タイムライン軸ラベルのフォーマット設定。初期実装では表示粒度ごとの既定フォーマットを使い、将来的に `1900` / `1900年` などの表記を選べるようにする。
- 時間粒度の分・秒対応。タイムラインの最小単位として分・秒を選べるようにし、詳細パネル入力、ドラッグのスナップ、依存遅延、SVG の表示粒度も拡張する。

## 仕様検討が必要

実装前に振る舞い、データ構造、UI などの検討が必要な項目を置く。

- 紀元前や 5 桁以上の年を含む長期年表への対応。現在の日時形式 `YYYY-MM-DDTHH:mm:ss` と date-fns 前提では扱える範囲が限られるため、保存形式、検証、表示、依存計算への影響を含めて検討する。
