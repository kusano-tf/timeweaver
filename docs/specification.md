# Timeweaver 仕様書

## 目的

Timeweaver は、タイムライン情報や年表のようなデータを可視化・編集する、バックエンド不要の Web アプリケーションである。

初期版は汎用タイムライン編集ツールとして実装する。プロジェクト管理専用、歴史年表専用、創作設定専用には寄せず、期間アイテム・時点アイテム・依存関係・タグ・表示状態を JSON ファイルとして入出力できることを重視する。

## 技術方針

- React / TypeScript で実装する。
- ビルド基盤は Vite を使う。
- パッケージ管理は pnpm を使う。
- lint / format は Biome を使う。
- 日付計算は date-fns を使う。
- JSON の構造・型・形式検証は Zod を使う。
- 状態管理は React の `useReducer` と Context を基本にする。
- 依存伝播、検証、日付計算などのドメインロジックは純粋関数として分離する。
- タイムライン本体は SVG 中心で描画する。

## 初期版スコープ

初期版では次の機能を必須とする。

- JSON インポート / エクスポート
- Zod による厳格な JSON 検証
- 期間アイテムと時点アイテムの表示
- アイテムの詳細編集
- アイテムのコピー
- 手動レーン配置
- タグの作成・削除・編集・並べ替え・フィルタ
- レーンの作成・削除・並べ替え
- 表示粒度の切り替え
- 表示範囲のズームイン / ズームアウト / パン
- Finish-to-Start 依存関係の表示・編集
- アイテムのドラッグ移動
- 依存先方向への自動伝播
- 現在表示中のタイムライン範囲の PNG / SVG 出力
- 全アイテムを対象とする Mermaid Gantt 形式の出力
- サンプルタイムラインの初期表示
- `docs/` と `.agents/` のドキュメント整備

初期表示用のサンプルタイムラインは、複数の依存元や依存先を持つ依存関係を含み、依存ビューや依存線の表示確認に使える内容にする。

初期版では次の機能は必須としない。

- Undo / Redo
- バー端ドラッグによる期間リサイズ
- 依存線のドラッグ作成
- 範囲選択によるアイテム作成
- UI E2E テスト
- 数千件以上のアイテムに向けた仮想化や高度な描画最適化
- 複数ビュー保存
- 自動保存
- リロード後の作業データ自動復元

## 日時

日時は秒精度まで保持する。

保存形式はタイムゾーンなしのローカル日時文字列とする。

例:

```json
"2026-07-13T09:30:00"
```

曖昧日付は扱わない。ユーザーが確定日時に補完してから入力する前提とする。

期間アイテムは開始・終了をともに含む閉区間 `[start, end]` とする。`start` と `end` は時間粒度の開始境界であり、`end >= start` を許可する。同じ値は最小単位1つの期間を表す。

UI での日時編集は時間粒度に合わせる。年は年、月は年月、日は日付、時は時までを入力し、保存時は対応する暦境界を持つ `YYYY-MM-DDTHH:mm:ss` 形式へ正規化する。

## アイテム

時点アイテムと期間アイテムは同じ `items` 配列に格納し、`type` で分岐する。

- 時点アイテム: `type: "instant"` と `at` を持つ。
- 期間アイテム: `type: "duration"` と `start` / `end` を持つ。

共通属性として、ID、タイトル、説明、レーン、タグ、色などを持てる。

## 依存関係

初期版の依存関係は Finish-to-Start のみを実装する。

基本式:

```text
to.start = from.end + (lag + 1) * timeline.granularity
```

`lag` はタイムラインの時間粒度で数える整数で、正・ゼロ・負を許可する。ゼロは先行終了の次の最小単位から開始する。

依存関係は循環禁止とする。依存追加時と JSON インポート時に循環を検出し、循環する依存は受け入れない。

初期版の自動伝播は依存先方向のみとする。`fromId -> toId` の向きでのみ後続アイテムを移動する。

先行アイテムの終了日時、時点アイテムの日時、またはタイムライン上での横方向ドラッグを確定する際、後続がある場合は「後続に伝播する」または「このアイテムだけ変更する」を選択する。確認UIでは後続件数を表示し、キャンセル時は日時変更自体を取り消す。

「後続に伝播する」を選んだ場合、直接・間接を問わない全後続を、対象アイテムと同じ暦上の時間粒度数だけ移動する。期間アイテムは期間の長さを維持して `start` と `end` を移動し、接続する `lag` を再計算する。

「このアイテムだけ変更する」を選んだ場合、後続アイテムは移動せず、接続する `lag` を現在の配置に合わせて再計算する。期間アイテムの開始日時だけの変更とレーンだけのドラッグは、後続へ影響しないため確認なしで確定する。

アイテムを手動移動した場合や依存伝播によって位置が変わった場合は、そのアイテムに接続する依存関係の `lag` を現在の配置に合わせて再計算する。

詳細パネルの先行依存では、依存関係の `lag` を現在の時間粒度による整数で編集できる。

`lag` の編集を適用した場合は、編集対象の依存関係を優先し、依存先アイテムの開始日時を `from.end + (lag + 1) * timeline.granularity` に一致させる。依存先アイテムは前後どちらにも移動できる。

依存先アイテムに複数の先行依存がある場合でも、編集対象の依存関係を優先して依存先アイテムを移動する。その他の先行依存の `lag` は、移動後の配置に合わせて再計算する。依存先アイテムの後続は、既存の依存伝播と同様に、制約違反が発生した場合だけ後ろへ移動する。

タイムライン下部には開閉可能な依存ビューを表示できる。初期状態は閉じた状態とし、開閉状態は JSON には保存しない。依存ビューはドキュメント内の全依存関係を、先行アイテムの開始日時、後続アイテムの開始日時、依存 ID の順で表示する。列は先行アイテム、後続アイテム、時間差、操作とする。操作列からは詳細パネルと共通の遅延編集モーダルを開け、依存関係を即時削除できる。編集時は対象依存を選択し、選択中の依存を削除した場合は選択を解除する。

依存ビューの行またはタイムライン上の依存線をクリックすると、その依存関係を選択し、依存先アイテムを詳細パネルで選択する。選択中の依存関係は、依存ビューの行、タイムライン上の依存線、詳細パネルの先行依存行で強調表示する。依存を選択しても表示範囲の自動移動は行わない。

詳細パネルは表示 / 非表示を切り替えられる。初期状態は表示とし、非表示時も右端に再表示用の細いレールを残す。詳細パネルの開閉状態は JSON には保存しない。詳細パネルを閉じた状態でアイテムや依存を選択しても、詳細パネルは自動では開かない。

タイムライン本体の見た目は、タイムライン JSON とは独立した現在テーマで管理する。組み込みの `"light"` / `"dark"` を選択でき、テーマ JSON を個別に保存・読込できる。タイムライン JSON を読込しても現在テーマは変えず、テーマ JSON はテーマメニューから読込する。現在テーマはブラウザのローカルストレージに 1 件だけ保持する。テーマは SVG タイムライン本体と PNG / SVG エクスポートの見た目に適用し、依存ビュー、タイムライン操作バー、詳細パネル、設定パネルなどのアプリ UI には適用しない。

テーマ設定は最上部ヘッダーのメニューから開くダイアログで操作する。設定はキャンバス、時間軸、レーン、依存関係、アイテムごとにまとめ、色と線幅を編集できる。時間軸の線・目盛り線とレーン境界線は別トークンとし、線幅は `0.5`〜`8px` の `0.5px` 刻みで指定する。編集中は即時プレビューし、保存で現在テーマへ確定する。キャンセル、閉じる、`Esc` はプレビューを破棄する。各項目とテーマ全体を選択中のプリセット値へ戻せる。任意のテーマ JSON 読込後のリセット基準はライトテーマとする。プリセットを選択して保存すると、カスタムテーマを解除してそのプリセットの既定値へ戻る。テーマはメニューの「テーマを保存」で単独 JSON として書き出す。アイテムのタグ色はテーマでは変更しない。画面上の選択強調色はテーマに応じて見やすい色にするが、エクスポート時には選択状態を出力しない。

将来の拡張として、Start-to-Start、Finish-to-Finish、Start-to-Finish、逆方向伝播、双方向伝播に対応できる余地を残す。

## レーン

初期版の縦方向配置は手動レーン方式とする。

JSON は `lanes` 配列を持ち、各アイテムが `laneId` で所属レーンを参照する。

同一レーン内で表示上重なるアイテムは、レーン内のサブ行へ自動的に上下配置する。サブ行は表示時のレイアウトであり、JSON には保存しない。

レーンは UI から追加・削除できる。アイテムが配置されているレーンは削除できない。

レーン管理一覧ではドラッグハンドルによる並べ替えができる。並べ替え後は `order` を `0` 始まりの連番へ正規化し、タイムライン本体の縦方向表示にも即時反映する。

レーン名は複数行のプレーンテキストを許可する。追加・編集はテキストエリアで行い、通常の Enter と `Shift` + Enter で改行、`Ctrl` / `Cmd` + Enter で新規レーンを追加する。SVG のレーン見出しは改行位置で複数行表示し、必要な場合はレーン領域の高さを広げる。Mermaid 出力では改行を空白へ正規化する。

レーン管理は通常の編集画面からは隠し、タイムラインのサマリー行にある設定ボタンから開く設定パネル内で行う。基本画面ではアイテム追加とタイムライン編集に集中できる構成とする。

## タグ

タグはフィルタ用途と色情報を持つ。

タグは UI から追加・削除・並べ替えできる。タグを削除した場合、そのタグ ID は各アイテムの `tagIds` と表示フィルタから取り除く。削除タグを `colorTagId` で参照しているアイテムは `colorTagId` を `null` に戻す。

タグ名とタグ色は追加後も編集できる。タグ管理は通常の編集画面からは隠し、タイムラインのサマリー行にある設定ボタンから開く設定パネル内で行う。

タグ管理一覧ではドラッグハンドルによる並べ替えができる。並べ替え後は `order` を `0` 始まりの連番へ正規化する。タグ管理の並べ替えでは、各アイテムの `tagIds` 順序は変更しない。

表示色の優先順位は次の通り。

1. アイテムの `color`
2. `colorTagId` で指定したタグの `color`
3. `tagIds` の先頭タグの `color`
4. デフォルト色

`colorTagId` は、アイテムに付いているタグの中から自動色に使うタグを指定する。`null` の場合は `tagIds` の先頭タグの色を使う。タグ追加時は `colorTagId` を自動変更しない。タグ解除やタグ削除で `colorTagId` が参照不能になった場合は `null` に戻す。

タグフィルタは OR / any とする。選択したタグのどれか 1 つでも付いているアイテムを表示する。

タグ未設定アイテムは、タグフィルタが空のときだけ表示する。タグが 1 つでも選択されているときは非表示にする。

タグは UI 上ではピル型の見た目で表示する。詳細パネルでは、設定済みタグをピル一覧として表示し、既存タグを検索して追加できる。詳細パネルから新規タグは作成しない。

## 表示

初期版の表示設定は単一の `view` とする。

表示粒度は次を扱う。

- `year`
- `month`
- `day`
- `hour`

データは秒精度まで保持するが、分・秒はタイムラインヘッダーの初期表示粒度には含めない。

タイムライン SVG の領域は、最下層の **キャンバス背景**、上段の **時間軸ヘッダー**、ヘッダー下の各 **レーン領域**、各レーン領域左側の **レーン見出し**、レーン見出しを除く右側の **プロット領域** と呼ぶ。キャンバス背景は SVG 全体を覆う。時間軸ヘッダーはプロット領域の左端から SVG 右端までを覆い、レーン領域は SVG の左右端までを覆う。キャンバス背景が露出してよいのは、時間軸ヘッダーとレーン見出しが交差する左上領域だけとする。SVG は最下レーンの末尾で終わり、下部にキャンバス背景の余白を設けない。

`year` 表示では、表示範囲と描画幅に応じて目盛り間隔を自動調整する。数年程度の範囲では 1 年単位、数十年から数百年の範囲では 5 / 10 / 25 / 50 / 100 年単位などに間引き、目盛り線とラベルを暦上のきりのよい年境界へ揃える。強調表示する上位境界は、目盛り間隔のおおむね 10 倍以上のきりのよい年単位から自動選択する。

時間軸ヘッダーは、境界ラベルが表示範囲内にある場合は2段にする。上段には上位境界、下段には通常目盛りを置き、境界自身も通常目盛りラベルを必ず表示する。境界がない場合は通常目盛りラベルを上下中央に置く。既定書式は、月表示では上段 `YYYY` / 下段 `MM`、日表示では上段 `YYYY-MM` / 下段 `DD`、時表示では上段 `MM-DD` / 下段 `HH` とする。書式は将来の表示設定で差し替え可能な派生表示とする。

`hour` / `day` 表示では、目盛り線とラベルの間隔を表示範囲と描画幅から派生させ、JSON には保存しない。日表示では通常ラベルを必ず生成済みの目盛り線と同じ間隔で表示し、月内の日付を基準に再間引きしない。月初の境界下段ラベルと通常ラベルが24px未満まで近接する場合だけは、境界ラベルを優先して通常ラベルを省略する。時表示では重なりを避けるため、ラベルを目盛り線より粗く間引ける。

表示範囲は `view.visibleRange` に保存する。`null` の場合は表示対象アイテム全体を自動表示し、ズームまたはパン後は `start` / `end` を持つ時間範囲として保存する。既存 JSON との互換性のため、インポート時に `visibleRange` が欠けている場合は `null` として扱う。

ズーム操作は表示範囲を狭める / 広げる方式とし、1 回のズームインで表示範囲を 1/2、ズームアウトで 2 倍にする。ボタン操作は現在表示範囲の中央を基準にする。`Ctrl` + ホイール操作はマウスカーソル位置の時刻を基準にズームする。通常ホイールは縦スクロールに残す。

`Shift` + ホイール操作では表示倍率を変えずに左右へパンする。ズーム範囲は最小 1 時間、最大は自動算出される全体範囲の 4 倍程度に制限する。表示粒度を切り替えても `visibleRange` は維持する。

右上メニューには開発者向けの「デバッグ情報を表示」を置く。これはブラウザの同一タブ内でのみ表示状態を保持する非保存UIであり、タイムライン JSON、未エクスポート状態、PNG / SVG / Mermaid 出力には影響しない。表示中は、表示範囲・派生拡大率・描画寸法・目盛り間隔・選択対象・ドラッグ状態などを画面右下の閲覧専用オーバーレイへ表示する。

ズーム済み表示中にアイテムを追加・移動して表示範囲外へ出ても、表示範囲は自動追従しない。時点アイテムは時刻が表示範囲内の場合だけ描画する。期間アイテムは表示範囲に一部でも重なれば描画し、範囲外にはみ出す部分は SVG 表示領域でクリップする。依存線は両端のアイテムが表示対象に含まれる場合だけ描画する。

## 編集

タイムライン上の直接操作は、初期版では次に絞る。

- アイテム選択
- ドラッグによる日時移動
- ドラッグによるレーン変更

アイテムのドラッグ中は、保存データを更新せず、ドラッグ対象アイテムだけをライブプレビューとして表示する。元位置には半透明のゴーストを残す。ドラッグ中と確定時の移動モードは、現在の横移動量と縦移動量から判定し、日時移動とレーン移動を同時には行わない。横移動が優勢な場合は日時だけを移動し、縦移動が優勢な場合はレーンだけを移動する。斜め方向で判定が曖昧な場合は直前の移動モードを維持し、未確定の場合は日時移動として扱う。

時間粒度はタイムライン設定で選ぶ年・月・日・時の最小単位であり、すべてのアイテム日時をその暦上の開始境界へ制約する。詳細パネルは粒度ごとに年、年月、日付、時までの入力を表示する。横ドラッグは表示粒度ではなく時間粒度へスナップし、期間・後続は同じ暦上の単位数だけ移動する。依存がある場合、または既存アイテムが整列していない場合は時間粒度を変更できない。

細かい編集は詳細パネルで行う。

- タイトル
- 説明
- 日時
- タグ
- 色
- 依存関係
- レーン

詳細パネルからアイテムをコピーできる。コピー時はアイテム本体のみを複製し、新しい ID とコピー用タイトルを付与する。依存関係は自動コピーしない。

タグ・レーンの管理操作は詳細パネルではなく設定パネルに集約する。詳細パネルでは、アイテムに既存タグを付け外しする操作のみを扱う。

タイムライン全体のタイトルと説明は、タイムラインのサマリー行にある設定ボタンから開く設定パネルで編集する。タイトルは必須で、空文字は確定しない。説明は空文字を許可し、空の場合は上部サマリーに表示しない。

## 保存モデル

初期版では自動保存しない。

ブラウザ内の作業状態は即時更新されるが、JSON ファイルへの永続化はユーザーがエクスポートしたときだけ行う。

`localStorage` などによるリロード後の作業データ自動復元は行わない。

未エクスポート変更がある場合は、離脱確認を表示する。

## インポート

JSON インポートは厳格検証する。

不正データがある場合は、ファイル全体を読み込まず、検証エラー一覧を表示する。

部分的な読み込みや暗黙の補正は行わない。

## 画像・Mermaid 出力

画像出力は、現在表示中のタイムライン範囲を PNG または SVG として出力する。

JSON のインポート / エクスポートはデータの保存・復元として扱う。PNG / SVG 出力は見た目の書き出しとして扱い、ヘッダーのその他の出力メニューに配置する。

Mermaid 出力は派生出力であり、インポートには対応しない。その他の出力メニューからダイアログを開き、生成した Mermaid Gantt 定義を読み取り専用テキストエリアで確認できる。ダイアログでは定義をクリップボードへコピーでき、`.mmd` ファイルとしてもダウンロードできる。コピーの成功・失敗はダイアログ内に2秒間表示する。全アイテムをレーン順・開始日時順で Mermaid Gantt の `section` / タスクとして出力する。期間アイテムは開始・終了日時、時点アイテムは `milestone` として表現し、日時は秒精度を保つ。依存関係、タグ、色、説明、表示範囲・フィルタ・テーマなどは出力しない。Mermaid 出力は JSON の未エクスポート状態を解除しない。

SVG 出力では、PowerPoint など外部アプリで見た目が保たれるよう、タイムライン描画に必要なスタイルを SVG 内に埋め込む。

出力対象:

- タイムライン本体
- 表示粒度
- 表示範囲
- タグフィルタ
- レーン
- 依存線
- 色

出力対象外:

- 画面外にスクロールしている領域
- 編集パネル
- ツールバー

## 性能目標

初期版は数百アイテムを快適に扱えることを目標とする。目安は 500 件前後とする。

数千件以上の大規模データ向け最適化は初期版では必須としない。

## テスト

初期版では Vitest によるドメインロジックの単体テストを必須とする。

重点対象:

- 期間アイテムと時点アイテムの Zod 検証
- 不正日時の拒否
- 閉区間 `[start, end]` の `end >= start` 検証
- 存在しない ID 参照の拒否
- 循環依存の検出
- Finish-to-Start 依存の後続伝播
- 後続手動移動時の粒度単位 `lag` 再計算
- タグ OR フィルタ

UI E2E テストは初期版では後回しにする。
