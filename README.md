# Timeweaver

Timeweaver は、タイムライン情報や年表のようなデータを可視化・編集する、バックエンド不要の Web アプリケーションです。

初期版は汎用タイムライン編集ツールとして実装します。期間アイテム、時点アイテム、依存関係、タグ、表示状態を JSON ファイルとしてインポート / エクスポートできることを重視します。
